  ↑/↓ move · ↵ select · q quit

Safe cache clean

Browsers keep cookies, history, logins, bookmarks. Only Cache/, Code Cache/, GPUCache/ get touched.

Build-artifact discovery

Finds node_modules/, target/, venv/, __pycache__ across your project roots — each its own selectable row.

Read-only health check

XProtect, LaunchAgent heuristics, codesign audit, quarantine review, outdated-package scan. Never modifies files.

Agent tools

Browse and prune Claude / Codex / Gemini skills and MCP server configs with explicit confirmation.
